## 2. 已知抖动与判读（如实记录，不算缺陷）

1. **首播可能被折回列表页**：实测首次带 token 直链请求时，站点有时返回 HTML 而不是视频字节。
   连续播放两次即稳定。应用侧依赖 `refreshVideoDetails` 重试；只要**重试后能播**
   即判 QA-6 通过，并把发生次数记进结果。
2. **会话预热**：只要详情页拿到的是正确的视频（对照列表标题/海报），
   说明预热路径生效；若拿到别人的视频，属真实缺陷，须记录 `viewkey`。
3. **限流 436**：站点偶发返回限流页，重试即 200。巡检脚本已带重试；
   人工验收遇到时等待数秒重试，不记为缺陷。
