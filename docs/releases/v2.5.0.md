# HaRu 2.5.0

本版本全面适配了 Rule34Video 站点的全新页面结构，彻底解决了封面黑屏、历史记录不同步、收藏提示 HTTP 403 等问题；新增了 Hanime 网页端登录支持（支持 Google 快捷登录与 Cloudflare 过盾）；并修复了部分 Android 手机冷启动闪退的兼容性问题。

## Rule34Video 站点改版适配与核心功能修复

- **修复封面大面积黑屏**：站点改版后对首屏后（第 5 张起）的卡片启用了延迟加载，现已全面支持读取 `data-rd-src`、`data-rd-webp` 及 `data-rd-jpg` 属性，所有封面图均可正常呈现；
- **适配新版个人中心结构**：全面适配站点 Member Area 新版排版，修复媒体库中历史记录、收藏和播放列表出现空列表的问题；
- **修复收藏提示 HTTP 403**：添加了对站点写操作安全令牌（CSRF Token）的自动申请与失效重试机制，加入或移出收藏不再报错；
- **修复云端观看历史未同步**：接入官方播放器起播打点机制，在 App 内播放视频后会即时同步至 Rule34Video 网页端观看历史；
- **优化搜索分页与错误提示**：更新搜索区块分页参数（`from_videos`）；支持直接解析并展示站点返回的结构化错误提示。

## Hanime 体验优化

- **新增网页授权登录**：支持在内置安全视窗中登录 Hanime，完美支持 Google 快捷登录与 Cloudflare 验证，登录成功自动同步至 App；
- **移除失效的找回密码入口**：由于 Hanime 官方未开放该功能（此前点击会跳转 404 错误页），App 内已相应下线该冗余入口；
- **完善连续播放信息**：优化播放列表界面的剧集与元数据展示，观看进度更清晰。

## 设备兼容性与稳定性提升

- **修复部分机型冷启动闪退**：针对无 Google Play 服务（GMS）的原生与国行机型，为网络引擎增加了自动优雅降级机制，彻底解决冷启动时抛出 `All available Cronet providers are disabled` 崩溃的问题；
- **内嵌独立网络内核**：构建包正式打包内置 Chromium 网络引擎（`cronet-embedded`），全设备网络连接更加稳定高效。
