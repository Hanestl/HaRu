# HaRu 2.1.0

这是一次面向视频详情页体验的改进版本，重点优化滚动稳定性、系列播放列表和评论交互。

## 视频详情与播放器

- 保留系统状态栏安全区，移除详情页独立标题栏，让播放器直接成为首屏内容；
- 未全屏播放器控制区增加返回按钮；
- 修复暂停播放器折叠后评论输入、置顶和页签切换引发的意外展开；
- 播放态置顶改为单一路径，避免 NestedScrollView 外层与内层互相争抢滚动距离。

## Hanime 系列视频

- 详情页简介下新增“系列视频”区域，可展开底部系列面板；
- 面板支持单列或双列显示，当前视频以“正在播放”标记；
- 打开面板时当前视频会直接定位到接近视口中央；
- 点击当前视频只关闭面板，不重复创建同一个详情页；
- 系列卡片采用惰性构建，降低长系列滚动时的渲染压力。

## 评论与性能

- 评论页签改为切换后再加载，详情页打开简介时不会同时构建大量评论；
- 评论输入框会保存并恢复用户所在的评论位置，关闭键盘后不会锁死页面操作；
- 翻译监听和卡片绘制范围收敛，改善详情页、系列面板和长按编辑译文的响应。

## 升级说明

- 仍只发布 Android `arm64-v8a` APK，最低支持 Android 7.0（API 24）；
- Android 包名、签名证书和本地数据标识保持不变，可直接覆盖升级；
- 本项目与 Rule34Video、Hanime 官方均无关联。
