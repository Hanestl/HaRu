# HaRu 2.6.1

本次为 2.6.0 的缺陷修复版本，主要解决 Rule34Video 观看历史被首页视频污染的问题。

## Rule34Video 观看历史修复

- **问题现象**：打开「媒体库 → R34V → 历史」会看到一批从未点开过的视频，而且恰好是首页 / 榜单里的最新内容；下拉刷新后历史条目还会继续变化；
- **根本原因**：Rule34Video 服务端只要收到视频详情页请求就会把该视频写入账号的观看历史（不依赖播放器打点）。2.6.0 为加快详情页打开速度，会在首页与榜单加载后预测性预取前 3 个视频的详情页，于是这些「用户根本没点开」的视频被服务端记成了已观看；
- **修复方式**：预测预取现在只对 Hanime 生效；Rule34Video 仅在用户真正打开视频详情页时才请求详情，历史不再被预取请求写入。Hanime 的历史由播放接口单独上报，原有的预取加速保持不变；
- **清理旧数据**：已经被写入的历史条目属于站点账号数据，如需删除请到 Rule34Video 网页端「My History」自行清理；本站内后续新产生的记录将只来自用户真实打开的视频。

> 已安装 2.6.0 的用户可以直接在「我的 → 关于 HaRu → 检查更新」中一键更新到本版本。
