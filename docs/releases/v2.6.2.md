# HaRu 2.6.2

本次是 2.6.1 之后的稳定性版本，汇总了 2.6.1 以来的 14 个提交，重点在网络请求、下载收尾与界面崩溃三处。

## 网络与账号

- **Cookie 存储失败不再拖垮整个应用**：当系统 Keystore 无法解锁（恢复过备份、更改了锁屏方式、安全存储损坏）时，Cookie 的读写异常此前会被网络层当成网络错误，导致所有请求看起来都失败。现在存储失败自动降级：本次运行内照常请求，只是无法在重启后恢复登录；错误会记录到日志；
- **被限流时给出明确等待时间**：请求被限流（429/503）时不再立刻重试，会解析服务端返回的 Retry-After，超出 2 秒重试预算就直接提示需要等待多久，并在退避中加入抖动；
- **Hanime 后台请求更克制**：后台预热、频道刷新与预取请求统一排队，前一项结束至少 300ms 后才发下一项，前台请求仍然直连；校验 Cloudflare 前先核对目标页面身份，避免把别的页面误判为验证完成。

## 下载

- **下载完成的收尾更可靠**：此前插件记录被删除后，完成事件可能落在关闭阶段而丢失，任务会一直停在「下载中」。现在平台层先把完成的下载写入本地库再删除插件记录，关闭时等待收尾结束；重复完成、私有源文件已被清理等情况都会给出可操作的提示，而不是让任务留在队列里重复下载。

## 界面与稳定性

- **页面退出不再崩溃**：登录弹窗、评论区、Hanime 媒体库、播放列表与订阅按钮在等待网络或弹窗返回后会无条件刷新界面，中途退出页面就会触发 setState 断言；相关路径均已加保护；
- **一键更新不再重复提示**：每次尝试安装都会新增一个安装结果监听器且从不取消，导致同一次安装结果被重复上报、旧页面被持续持有；现在只处理首次结果并在所有分支取消订阅；
- **返回顶部按钮更稳**：不再在构建或点击时现场查找焦点祖先，避免读取已释放的节点触发框架断言；
- **新增中文兜底页**：打开不存在的页面时显示「页面不存在」与「返回首页」，与全局错误页风格一致，不再出现英文默认页；
- **本地库与播放列表消失时给出提示**：目标库或播放列表被删除后，不再抛出 StateError。

## 性能

- **连播播放列表内存可控**：只保留最近 6 条视频详情的缓存，并始终保留当前条目，缓存 miss 时重新请求；
- **下拉刷新合并请求**：刷新期间连续触发的重置会合并为一次按最新条件的重放，减少重复的分页请求；
- **日志读写更省**：缓存当前日志文件与大小，读取全部日志不再逐行 stat、重复拼接缓冲区。

## 关于升级

- 已安装 2.6.1 的用户可以直接在「我的 → 关于 HaRu → 检查更新」中一键更新到本版本，也可以下载下方 APK 覆盖安装；
- 本版本仍只提供 arm64-v8a 安装包，版本号 2.6.2，构建号 51；
- 安装包 SHA256 见 Release 附件 `SHA256SUMS.txt`。
