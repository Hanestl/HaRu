# HaRu 2.4.0

本版本让首页「订阅」频道改走站点聚合接口，显著加快首屏；并修复 Rule34Video 播放列表内视频加载不全、以及 App 内播放列表增删一律失败的问题。

## 首页「订阅」更快

- 「订阅」频道改为直接读取站点提供的聚合区块，站点已把全部订阅的视频汇成一个按发布时间倒序的列表；
- 首次加载从「每个订阅各请求一次、再在本地合并」变为「每页一次请求」，订阅数量较多时差别尤其明显；
- 同时移除了「正在整理订阅内容 x/y」的等待提示，因为不再需要在本地逐个整理；
- 媒体库中订阅列表的「最近更新」排序仍保留原有方式，它需要每个订阅各自的更新时间，聚合区块不提供该信息。

## Rule34Video 播放列表

- 修复播放列表内视频只能看到开头一小段的问题：此前会把播放列表解析成站点的管理页，而不是内容页，导致从第二页起请求不到数据。现在始终使用内容页地址；
- 修复在 App 内加入播放列表、移出播放列表、删除播放列表一律失败并提示 HTTP 403 的问题。站点要求先申请一次安全令牌，再随写请求一并发送；令牌失效时会自动重新申请并重试；
- 顺带修正删除播放列表使用了站点不接受的请求方式。
