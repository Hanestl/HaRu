# HaRu 2.3.0

本版本新增自定义时间与时长筛选，并修复 Rule34Video 账号播放列表加载不完整、Hanime 首页部分频道封面缺少统计信息等问题。

## 自定义筛选

- 首页和搜索的「发布时间」支持自定义起止日期，可只填开始或只填结束；
- 「视频时长」支持自定义最短/最长秒数，同样可只填一端；
- 起止顺序或数值无效时给出提示并拒绝应用；
- 媒体库中收藏、历史、播放列表和本地库的时长筛选同步支持自定义范围；Hanime 视频仍使用预设档位，因为该站点不支持自定义时长参数。

## Rule34Video 播放列表

- 账号播放列表的后续分页改用站点的 `list_playlists_my_created_playlists` 异步区块协议；
- 移除原先最多 50 页的限制，改为读取到末页结束；
- 若分页连续多页未取得新内容，会明确提示刷新重试，而不是返回一个不完整的结果；
- 只有完整加载成功后才会缓存结果。

## Hanime 首页频道

- 修复「里番」「泡面番」频道视频封面不显示发布时间、点赞率和观看数的问题，改为按首页分区数据回填。需要说明的是，这两个频道的列表接口只返回封面和标题，翻页后超出首页分区的条目仍无法显示这些信息。

## 其他修复

- 修复开发构建中打开媒体库播放列表或视频评论面板时触发 setState 断言、内容无法显示的问题；正式发布版本不受此问题影响。
